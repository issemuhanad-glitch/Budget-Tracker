# Personal Budget & Expense Tracker

## About the Project

This project is a Personal Budget & Expense Tracker built using HTML and CSS.

## What I Built

### Expense Form
The form allows users to enter:
- Expense name
- Amount
- Category
- Date

A category dropdown contains Food, Transport, Rent, Entertainment, and Other.

### Expense Table
The table displays sample expenses with:
- Name
- Amount
- Category
- Date

### Multimedia
The page includes a budget tracker logo and a YouTube video.

### Interactive Elements
A collapsible "How to use this tracker" section was added using details and summary.

### CSS Styling
CSS was used to style the form, table, buttons, rows, and input focus states.

## Technologies Used

- HTML
- CSS
