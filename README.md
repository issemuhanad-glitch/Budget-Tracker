# SpendWise – Personal Budget Tracker

## 1. Project Description

SpendWise is a personal budget tracking web application designed to help users manage their monthly budgets and monitor their expenses.

The application allows users to set a monthly budget, add expenses, view total expenses, calculate their remaining balance, and monitor spending by category.

SpendWise provides a simple and user-friendly dashboard that helps users understand and manage their spending habits.

## 2. Technologies Used

The project was developed using:

- **HTML5** – Provides the structure of the application.
- **CSS3** – Provides styling, layout, and responsive design.
- **JavaScript** – Handles application functionality, calculations, events, and dynamic updates.
- **Local Storage** – Saves budget and expense information in the browser.
- **Git and GitHub** – Used for version control and project hosting.
- **Netlify** – Used to deploy and publish the live website.

## 5. Deployment Process Summary

The following steps were completed to deploy SpendWise:

1. Reviewed the project structure and confirmed that all required files were organized correctly.
2. Uploaded and maintained the project files in a public GitHub repository.
3. Logged in to Netlify using the GitHub account.
4. Imported the existing Budget-tracker GitHub repository into Netlify.
5. Configured and deployed the website.
6. Confirmed that the deployment was successfully published.
7. Used the custom Netlify site address: https://spendwiseplp.netlify.app/
8. Opened the live website and tested its functionality.
9. Updated the dashboard heading to test automatic deployment.
10. Committed and pushed the changes to GitHub.
11. Verified that Netlify automatically detected the GitHub update and published a new deployment.
12. Removed the temporary deployment-test heading and published the final version.

## 6. Challenges Encountered During Deployment

During the deployment process, I encountered some challenges:

- **Repository connection:** I had to select the correct existing GitHub repository when importing the project into Netlify.

- **Verifying deployment:** I needed to confirm that the website was successfully published and accessible through its Netlify URL.

- **Testing automatic deployment:** I had to make a visible change to the application, push it to GitHub, and check whether Netlify automatically published the update.

- **Checking the live website:** I tested the deployed application to ensure that its layout, styling, JavaScript functionality, and expense management features were working correctly.

These challenges were addressed by checking the repository, reviewing deployment status, and testing the live website.
